# EY Deck Design 最小化优化审查

审查日期：2026-09-14。方法：Superpowers 独立审查、代码测试先行、完成前验证。以本轮开始时的工作区为基线，保留此前未提交修改。

## 覆盖与边界

- 文件清单包含 13,016 个文件：250 份 Markdown、280 份 Python、少量配置/界面代码，以及图标、模板、图像和音效等资产。
- 所有 Markdown 完成全文结构/重复描述扫描；47 个入口、流程及相关文件完整阅读。深度语义检查集中在实际 EY 调用路径、执行器/模板核心、相关分支及发现不一致的工具说明。
- 全部 280 份 Python 完成 AST 解析；内嵌部分为 265 文件、183,410 行、5,012 个函数。另检查配置 JSON/YAML 和 JS/HTML/CSS。代码采用静态扫描加重点调用链复核，不等同于逐行人工审阅全部源码。
- 资产、生成数据、许可声明及历史报告保留原样。独立品牌/样式模板的必要自包含规则保留；内嵌包未启用的通用流程不计作 EY 每页必做步骤。

## 验证证据

- 两项根流程效率测试在修改前均以 `2 != 1` 失败，修改后通过：一次展示只读一次审批策略；一次投影只计算一次来源哈希。第二次投影会重新计算已变动源文件的哈希。
- 实际 CLI 标记前检：两份真实 SVG 由 4 次 XML 解析降为 2 次；新增测试验证错误/诊断顺序、旧版标记、读取失败、来源字节及输出前阻断。
- 独立语义复核覆盖英文全文审核、两单元重点页、R2 局部反馈、运行环境复用，以及无基线回退全文/有效基线差异审核。
- EY 完整工作流 63 项测试通过，包含实际 PPTX 导出；内嵌导出/分组/一致性 68 项测试通过（含 3 项新增标记扫描测试）。Skill Creator 校验及修改文件空白检查通过。
- 原先绑定固定措辞的测试改为检查两项、三项、五项已批准内容范围经 bootstrap 原样传递；通常三至五项的上游要求仍有检查。
- 本轮只调整 12 个现有文件，新增 2 个测试文件和本报告。清单中的其余 13,004 个原有文件哈希未变。11 个修改的生产代码/文档文件合计减少 49 行。
- 本报告不推算整套制作耗时或模型 token 节省；列出的优化量均为字符数或具体测试场景中的调用次数。

## 本轮未扩大修改的候选

- 无图片页面的图像处理提前返回：可能减少树副本，但需进一步覆盖直接图片、defs/use 和图案图片后再改。
- 两份 `chart_read.py` 及其他 OOXML 重复读取器：共享实现需要保留各自兼容入口，收益与影响范围大于此次局部流程去重。
- 独立模板的相同保护规则、不同生命周期边界的重复哈希/校验继续保留。
